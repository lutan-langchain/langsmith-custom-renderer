Try this in order

  1. Open any trace in the project. The Output section becomes this page.
  2. Click a child LLM or tool run in the tree. The payload should switch to that run.
  3. Open the Output format dropdown and pick Markdown, then Custom again.
  4. Drag the bar under this panel to resize it.

Expected

  • type is "output" here; "reference" only for dataset reference outputs.
  • Inputs arrive as context under metadata.inputs, and are never themselves replaced.
  • Only the selected run's own payload arrives, never the child trace tree.
  • Message count resets on each run: the frame remounts per run, so this log covers the current run only.
